# Paso 5.2: Canales y Medios

## Canales y Medios

Este paso define como se llegara a los beneficiarios de la solucion.

Los canales o medios pueden incluir, entre otros:

- App.
- Portal interno.
- Correo.
- Capacitacion online.
- Capacitacion presencial.
- Documentos.
- Otros canales operativos o digitales.

## Preguntas que debe responder cada item

- Como se llegara a los beneficiarios?
- Que canal o medio se utilizara?
- El canal es adecuado para el grupo beneficiario definido en el Target?
- El canal facilita la adopcion de la solucion propuesta?

## Reglas

- La lista no puede estar vacia.
- No pueden existir items repetidos.
- Cada item debe estar escrito como una oracion clara.
- Cada item debe describir un canal o medio concreto.
- Cada item debe indicar como ese canal o medio ayudara a llegar a los
  beneficiarios.
- Debe mantener coherencia con la Vision, el Target, el Valor de Negocio, la
  Necesidad y la Solucion Propuesta definidos previamente.

## Tarea del modelo

1. Recibir una lista de items redactados como oraciones.
2. Validar si cada item describe un canal o medio concreto.
3. Validar si cada item explica como se llegara a los beneficiarios.
4. Evaluar si el canal o medio es coherente con el Target.
5. Detectar items repetidos, ambiguos o poco accionables.
6. Proponer una version corregida para cada item que no cumpla.
