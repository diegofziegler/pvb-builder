# Paso 5: Producto / Proceso / Servicio

## Solucion Propuesta

El paso Producto / Proceso / Servicio describe que se quiere crear, modificar o
incorporar como solucion para responder a la necesidad identificada.

Cada item debe explicar la solucion propuesta desde una de estas perspectivas:

- Producto a crear, incorporar o modificar.
- Proceso a crear, incorporar o modificar.
- Servicio a crear, incorporar o modificar.

## Preguntas que debe responder cada item

- Como se propone resolverlo?
- Que Producto, Proceso o Servicio se creara, incorporara o modificara?

## Reglas

- La lista no puede estar vacia.
- No pueden existir items repetidos.
- Cada item debe estar escrito como una oracion clara.
- Cada item debe describir una solucion propuesta, no solo una necesidad o un
  problema.
- Cada item debe indicar si se trata de un Producto, Proceso o Servicio.
- Cada item debe aclarar si se creara, incorporara o modificara algo.
- Puede usar terminos tecnicos, pero deben ser entendibles para un Jefe o
  Gerente. Si un termino tecnico no es claro para ese nivel de audiencia, debe
  explicarse o reemplazarse por lenguaje de negocio.
- Debe mantener coherencia con la Vision, el Target, el Valor de Negocio y la
  Necesidad definidos previamente.

## Tarea del modelo

1. Recibir una lista de items redactados como oraciones.
2. Validar si cada item describe una solucion propuesta.
3. Clasificar cada item como Producto, Proceso o Servicio.
4. Validar si cada item responde como se propone resolver la necesidad.
5. Validar si cada item indica que se creara, incorporara o modificara.
6. Detectar items repetidos, ambiguos, demasiado tecnicos para un Jefe o
   Gerente, o poco conectados con los pasos previos.
7. Proponer una version corregida para cada item que no cumpla.
