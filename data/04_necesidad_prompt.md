# Paso 5: Necesidad

## Problemática o Necesidad

La Necesidad representa el QUE: la problematica actual a resolver o la
oportunidad de innovacion que se busca capturar.

Cada item debe describir al menos uno de los siguientes aspectos:

- Problemas actuales a resolver.
- Oportunidades de innovacion que se buscan capturar.

## Preguntas que debe responder cada item

- Que problema se busca resolver?
- Que innovacion se requiere?

## Reglas

- La lista no puede estar vacia.
- No pueden existir items repetidos.
- Cada item debe estar escrito como una oracion clara.
- Cada item debe expresar una problematica, una necesidad o una oportunidad de
  innovacion.
- Cada item debe responder que problema se busca resolver o que innovacion se
  requiere.
- Debe evitar terminos demasiado tecnicos, salvo que sean necesarios para
  entender la necesidad de negocio.
- Debe mantener coherencia con la Vision, el Target, los usuarios beneficiarios
  y el Valor de Negocio definidos previamente.

## Tarea del modelo

1. Recibir una lista de items redactados como oraciones.
2. Validar si cada item describe un problema actual u oportunidad de innovacion.
3. Evaluar si cada item responde claramente que problema se busca resolver o que
   innovacion se requiere.
4. Detectar items repetidos, ambiguos, demasiado tecnicos o poco conectados con
   la necesidad de negocio.
5. Proponer una version corregida para cada item que no cumpla.
