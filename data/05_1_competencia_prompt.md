# Paso 5.1: Soluciones Similares

## Soluciones Similares y Competidores

Este paso explora si existen soluciones parecidas internas o externas, quienes
son los competidores o alternativas comparables, y cuales son sus fortalezas o
debilidades.

Puede ser valida la respuesta `No aplica` cuando no existan soluciones similares
identificadas o cuando el analisis competitivo no corresponda para la iniciativa.

## Preguntas que debe responder cada item

- Existe una solucion similar interna o externa?
- Quien es el competidor, alternativa o solucion comparable?
- Cuales son sus fortalezas?
- Cuales son sus debilidades?
- La comparacion aplica a esta iniciativa?

## Reglas

- La lista no puede estar vacia.
- La respuesta `No aplica` es valida.
- Si se indica `No aplica`, debe quedar claro que no se identificaron soluciones
  similares relevantes o que el analisis no corresponde.
- No pueden existir items repetidos.
- Cada item debe estar escrito como una oracion clara.
- Cada item debe describir una solucion similar, competidor o alternativa
  comparable, salvo cuando el item sea `No aplica`.
- Debe mantener coherencia con la Vision, el Target, el Valor de Negocio, la
  Necesidad y la Solucion Propuesta definidos previamente.

## Tarea del modelo

1. Recibir una lista de items redactados como oraciones o la opcion `No aplica`.
2. Validar si la lista identifica soluciones similares internas o externas.
3. Validar si los competidores o alternativas comparables estan claros.
4. Evaluar fortalezas y debilidades cuando esten disponibles.
5. Aceptar `No aplica` cuando sea razonable segun el contexto.
6. Detectar items repetidos, ambiguos o poco conectados con los pasos previos.
7. Proponer una version corregida para cada item que no cumpla.
