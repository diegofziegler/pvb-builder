# Paso 1: Vision

Objetivo: generar y validar la Vision de un Product Vision Board.

Reglas de la Vision:

- Debe ser redactada como una frase breve de 7 a 12 palabras.
- No puede estar vacia.
- Debe ser una oracion.
- Debe sintetizar la motivacion central de la iniciativa.
- Debe expresar el impacto positivo deseado.
- Debe estar orientada al negocio y tener un enfoque estrategico.
- Debe conectar la iniciativa con valor para **El Negocio**, por ejemplo:crecimiento, eficiencia, sostenibilidad, diferenciacion, calidad de servicio,experiencia del afiliado/paciente, productividad operativa o toma dedecisiones.
- No debe quedar redactada como una descripcion tecnica, una funcionalidad o unatarea de implementacion.
- Debe evitar terminos demasiado tecnicos, jerga interna o nombres decomponentes tecnologicos salvo que sean imprescindibles para el negocio.
- Debe responder:- Cual es la motivacion para crear una nueva solucion?
- Que cambio positivo deberia provocar?
- Que valor estrategico o de negocio deberia habilitar?

Tarea del modelo:

1. Interpretar los comentarios del usuario.
2. Proponer una Vision en una sola frase orientada a negocio y estrategia.
3. Validar si cumple las reglas.
4. Si no cumple, explicar brevemente que falta y proponer una version corregida.


# Formato de respuesta:

## Vision propuesta

<frase de 7 a 12 palabras>

## Validacion

- Extension: <cumple/no cumple, con cantidad de palabras>
- Oracion no vacia: <cumple/no cumple>
- Motivacion: <cumple/no cumple>
- Impacto positivo: <cumple/no cumple>
- Orientacion estrategica/de negocio: <cumple/no cumple>
- Lenguaje no tecnico: <cumple/no cumple>
- Coherencia con **el Negocio**: <cumple/no cumple>

## Ajustes sugeridos

<1 a 3 comentarios concretos, o "Sin ajustes relevantes.">

# Tarea adicional para el modelo

Sugiere un código para el proyecto. Esto es porque nosotros solemos *inventar* un código para cada proyecto nuevo. Este código nos permite identificarlo rápidamente. Debes basarte en la información suministrada para generar un código que usaremos como *ALIAS* para el proyecto. Este código debe apuntar a ser una palabra o nombre breve no más de 10 letras. Puedes seleccionar letras de las palabras que componen la visión, o puedes inventar un título y extraer el código de ese título inventado. Obviamente tiene que tener sentido respecto de la visión.
